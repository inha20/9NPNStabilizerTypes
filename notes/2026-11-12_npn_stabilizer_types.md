## 1. 정의와 방법

### 1.1 정의

$B_n = \mathbb{Z}_2^n \rtimes S_n$은 입력 반전과 변수 순열이 만드는 군이다. $G_n = B_n \times \mathbb{Z}_2$는 $(g, \varepsilon) \cdot f = (f \circ g^{-1}) \oplus \varepsilon$로 함수에 작용한다($\varepsilon$이 출력 반전). $K(f) \le G_n$은 $f$의 안정화군이고, 그 $G_n$-켤레류가 "나타나는 군"이다. $G_n$-궤도가 NPN 류, $B_n$-궤도가 NP 류이다. $H(f) = \{g \in B_n : f \circ g = f\}$(R9), $A(f) = \{g \in B_n : f \circ g = \lnot f\}$, $\bar K(f) = H(f) \cup A(f)$로 쓴다.

### 1.2 구조

**보조정리 1 ($K$는 그래프이다).** $(g, 0)$과 $(g, 1)$이 모두 $K(f)$에 있으면 $f = \lnot f$이므로 그럴 수 없다. 따라서 $(g, \varepsilon) \mapsto g$는 $K(f)$에서 $B_n$으로 가는 단사이고, 그 상 $\bar K(f)$ 위에서 $\varepsilon = \varphi(g)$는 준동형 $\varphi : \bar K(f) \to \mathbb{Z}_2$이다. $\ker \varphi = H(f)$이므로 $[\bar K : H] \le 2$이고 $A(f)$는 비어 있거나 $H(f)$의 잉여류이다. $\bar K(f)$는 $B_n$이 쌍 $\{f, \lnot f\}$에 작용할 때의 안정화군이다.

**보조정리 2 (반대칭 원소는 꼭짓점을 고정하지 않는다).** $a \in A(f)$이면 모든 꼭짓점 $x$에서 $f(ax) = \lnot f(x)$이므로 $ax \ne x$이다. 또 $x \mapsto ax$가 $f$의 값 0인 꼭짓점과 1인 꼭짓점을 맞바꾸므로 $f$는 균형이다. $\bar K(f)$가 어떤 꼭짓점을 고정하면 $A(f) = \emptyset$이다.

**보조정리 3 (고정점 수).** $L \le B_n$이고 $\varphi : L \to \mathbb{Z}_2$가 준동형이라 하자. 모든 $g \in L$에서 $f \circ g = f \oplus \varphi(g)$인 함수 $f$의 수는, $\varphi$가 모든 꼭짓점 안정화군 $L_x$에서 0이면 $2^{o(L)}$($o(L)$은 $L$의 꼭짓점 궤도 수)이고 아니면 0이다. 궤도마다 대표 꼭짓점 $x_0$의 값을 하나 고르면 $f(g x_0) = f(x_0) \oplus \varphi(g)$로 나머지가 정해지고, 이것이 잘 정의되려면 $g x_0 = x_0$인 $g$에서 $\varphi(g) = 0$이어야 하기 때문이다. 이런 $\varphi$ 전체 $V(L)$은 $\mathrm{Hom}(L, \mathbb{Z}_2)$의 부분군이므로 $\lvert V(L) \rvert = 2^k$이다. $\varphi \ne 0$이 $V(L)$에 속할 조건은 $N = \ker \varphi$(지수 2)의 꼭짓점 궤도 수가 $2\,o(L)$이라는 것과 같다(각 $L$-궤도가 $N$-궤도 둘로 갈라진다). 이런 $N$의 수를 $n_g(L)$이라 하면 $\lvert V(L) \rvert = 1 + n_g(L)$이다. $f$와 $\lnot f$는 같은 $\varphi$를 가지므로, $L$이 고정하는 쌍 $\{f, \lnot f\}$의 수는 $\tfrac12 \cdot 2^{o(L)} (1 + n_g(L)) = 2^{o(L) - 1 + k}$이다.

### 1.3 방법 B: $\bar K$ 단위의 표 ($n \le 6$)

$B_n$의 부분군 켤레류 $[L_j]$마다 쌍 위의 고정점 수 $2^{o(L_j) - 1}(1 + n_g(L_j))$를 구하고, 이 벡터를 $B_n$의 표지 표로 분해한다(GAP `DecomposedFixedPointVector`). 나오는 정수 $d_j$는 $\bar K$가 $L_j$와 켤레인 쌍의 $B_n$-궤도, 곧 NPN 류의 수이다. 그런 류 하나는 함수를 $2 \lvert B_n \rvert / \lvert L_j \rvert$개 가진다. 지수 2인 부분군은 $L$ 안의 제곱들이 생성하는 정규부분군으로 나눈 몫이 초등 아벨 2-군이라는 사실로 모두 구한다(몫의 극대 부분군을 끌어올린다). 이 방법은 $\bar K$까지만 주고 $\varphi$(곧 $H$)는 주지 않는다. $n = 6$까지 된다(GAP 428초).

### 1.4 방법 A: $K$ 단위의 표 ($n \le 5$)

$G_n$을 $2^n + 2$개의 점(꼭짓점 $2^n$개와 출력 반전이 맞바꾸는 두 점) 위의 순열군으로 놓고 표지 표를 만든다. 켤레류 $[K_j]$의 고정점 수는, $K_j$가 출력 반전 단독 원소 $(1, 1)$을 가지면 0이고, 아니면 $K_j$가 정하는 $\varphi_j$가 보조정리 3의 조건을 만족할 때 $2^{o(\bar K_j)}$, 아니면 0이다. 분해하면 $K(f)$가 $K_j$와 켤레인 NPN 류의 수 $d_j$가 나오고 함수는 $d_j \lvert G_n \rvert / \lvert K_j \rvert$개이다. 이 방법은 $\varphi$까지 준다. 군마다 대표 함수를 무작위 탐색(작으면 전수)으로 찾아 안정화군이 정확히 그 군임을 직접 확인했다. $n = 6$은 시도했으나 표지 표가 끝나지 않았다(5절). $n = 6$의 $K$ 단위 표는 1.6절의 방법 C로 구했다.

### 1.5 류 수의 관계

보수 취하기는 NP 류($B_n$-궤도)들 위의 대합이다. 제자리에 놓이는 류가 자기보수 류, 곧 $A(f) \ne \emptyset$인 류이고 그 수를 $s$라 하면 NPN = $s$ + (NP $- s$)/2이므로 $s = 2\,\mathrm{NPN} - \mathrm{NP}$이다. 이 식 때문에 NP 류 수(OEIS A000616: 3, 6, 22, 402, 1,228,158, 400,507,806,843,728)와 NPN 류 수의 두 값으로 반대칭 류의 총수가 정해지고, 반대칭이 없는 류의 수는 NP $-$ NPN이다.

### 1.6 방법 C: $B_n$의 표지 표 하나로 $K$ 단위의 표를 구한다 ($n \le 6$)

방법 A는 $B_n \times \mathbb{Z}_2$의 표지 표가 필요한데 이 표는 $n = 6$에서 만들지 못했다(5절). 방법 C는 $B_n$의 표지 표만 쓴다. $K(f)$는 쌍 $(L, \varphi)$이므로(보조정리 1) 알아내야 할 것은 "$\bar K$가 $L_j$와 켤레인 NPN 류 가운데 $\varphi$가 이러이러한 것이 몇 개인가"이다. 두 단계로 푼다. 먼저 $B_n$의 표지 표에서 정수 일차방정식을 세워 풀고(C1), 방정식이 정하지 못하는 칸은 함수를 직접 열거해 센다(C2). 보조정리 4, 5와 (C2)의 식은 저자 검토가 필요하다. `[저자]`

**서명과 미지수.** $B_n$에서 $\mathbb{Z}_2$로 가는 준동형은 $0$, $\psi_1$(변수 순열의 부호), $\psi_2$(반전한 변수 수의 홀짝), $\psi_3 = \psi_1 + \psi_2$ 넷이다($n \ge 2$; $B_n = \mathbb{Z}_2 \wr S_n$의 가환화가 $\mathbb{Z}_2^2$이다). $L \le B_n$ 위의 유효한 $\varphi$(보조정리 3의 $V(L)$)마다 서명 $\mathrm{sig}(\varphi) = (\kappa, t_1, t_2, t_3)$을 정한다. $\kappa$는 $\ker \varphi$의 $B_n$-켤레류 번호이고($\varphi = 0$이면 $\kappa = 0$), $t_k$는 $\varphi = \psi_k|_L$이면 $-1$, 아니면 $\ker(\varphi + \psi_k|_L)$의 켤레류 번호이다. 켤레인 쌍 $(L, \varphi)$는 서명이 같다. 역은 보장되지 않으므로 $j$마다 "서명의 수 = 1 + ($N_B(L_j)$가 유효한 $\varphi \ne 0$들 위에서 가지는 궤도 수)"를 점검했다. $n = 3, 4, 5$에서는 $\bar K$로 나타나는 모든 $j$(8, 37, 177개)에서, $n = 6$에서는 1,137개 가운데 한 개를 뺀 모든 $j$에서 맞았다. 어긋난 $j$ 하나는 서명 3개가 $K$의 켤레류 4개를 나타내며 아래 (C2)로 갈랐다. 미지수는 $W[j, s]$ = "$\bar K \sim L_j$이고 서명이 $s$인 NPN 류의 수"이다.

**(C1) 꼬인 작용과 연립방정식.**

**보조정리 4 (꼬인 작용).** $\psi : B_n \to \mathbb{Z}_2$가 준동형이면 $g * f = (f \circ g^{-1}) \oplus \psi(g)$는 $B_n$이 함수 집합에 하는 작용이다. 이 작용에서 $f$의 안정화군은 $\{g \in \bar K(f) : \varphi_f(g) = \psi(g)\}$이다. NPN 류 하나가 $(L, \varphi)$이면 이 작용에서 (i) $\varphi = \psi|_L$일 때 안정화군이 $L$인 $B_n$-궤도 둘이 되고, (ii) 아닐 때 안정화군이 $\ker(\varphi + \psi|_L)$인 궤도 하나가 된다.

*증명.* $\Gamma_\psi = \{(g, \psi(g)) : g \in B_n\} \le G_n$은 $B_n$과 동형이고 지수 2이므로 정규이며, $*$는 $G_n$의 작용을 $\Gamma_\psi$로 제한한 것이다. $G_n$-궤도 $G_n f$가 $\Gamma_\psi$-궤도로 갈라지는 수는 $\lvert G_n : \Gamma_\psi K \rvert$($K = K(f)$)이다. $K \le \Gamma_\psi$(곧 $\varphi = \psi|_L$)이면 2이고 아니면 1이다. 궤도의 안정화군은 $K \cap \Gamma_\psi$이고 $B_n$으로 옮기면 (i)에서 $L$, (ii)에서 $\{g \in L : \varphi(g) = \psi(g)\}$이다. (i)의 두 궤도는 $G_n$의 중심 원소 $(1, 1)$이 맞바꾸고 안정화군은 그대로이다. $\square$

$U \le B_n$이 $*$에서 고정하는 함수의 수는 보조정리 3에서 $\varphi = \psi|_U$로 놓은 값이다. 곧 $\psi$가 $U$의 모든 꼭짓점 안정화군에서 0이면 $2^{o(U)}$이고 아니면 0이다. 이 고정점 수 벡터를 $B_n$의 표지 표로 분해하면 안정화군이 $L_x$와 켤레인 궤도의 수 $a_k[x]$를 얻는다($k = 0, 1, 2, 3$이 $\psi = 0, \psi_1, \psi_2, \psi_3$이다). $a_0[x]$는 $H(f) \sim L_x$인 $B_n$-궤도, 곧 R9 표의 NP 류 수이다. 보조정리 4에 따라 NPN 류가 이 궤도들에 기여하는 방식이 서명으로 정해지므로 $W$에 대한 정수 계수의 일차방정식이 나온다.

- (D) $\sum_s W[j, s] = d_j$. $d_j$는 1.3절의 NPN 류 수이다.
- (E$k$) $\sum_{j, s} c_k(j, s; x)\, W[j, s] = a_k[x]$ ($k = 0, 1, 2, 3$, 모든 켤레류 $x$마다). $c_k(j, s; x)$는 서명의 $k$째 성분이 "$-1$"이고 $j = x$이면 2, 그 성분이 $x$이면 1, 아니면 0이다. $k = 0$의 성분은 $\kappa$이고 $\kappa = 0$이 "$-1$"의 몫을 한다.

**보조정리 5 (패리티 대칭).** $c(x) = x_1 \oplus \cdots \oplus x_n$이면 모든 $g \in B_n$에서 $c \circ g = c \oplus \psi_2(g)$이다(순열은 $c$를 바꾸지 않고 입력 반전은 반전한 변수 수만큼 $c$를 뒤집는다). 따라서 $f \mapsto f \oplus c$는 NPN 류들 위의 대합이고 $(L, \varphi)$인 류를 $(L, \varphi + \psi_2|_L)$인 류로 옮긴다. 서명으로는 (SYM) $W[j, s] = W[j, \sigma(s)]$이고, $\sigma(\kappa, t_1, t_2, t_3)$은 $t_2 = -1$이면 0, 아니면 $t_2$를 첫 성분으로, $t_3$을 둘째로, $\kappa = 0$이면 $-1$, 아니면 $\kappa$를 셋째로, $t_1$을 넷째로 하는 서명이다.

방정식은 `scripts/solve_npn_pair_resolution.py`가 유리수 가우스-조던 소거와 "계수가 모두 양수인 방정식의 우변이 0이면 그 미지수는 모두 0"이라는 전파만 써서 푼다(해가 음수이거나 정수가 아니거나 방정식이 서로 모순이면 알린다). $n = 3, 4, 5$에서는 이 연립방정식이 미지수 16, 73, 451개를 모두 정하고(방정식 70, 274, 1,326개) 방법 A의 표와 한 칸도 다르지 않다. 꼬인 작용과 대칭을 빼고 (D)와 (E0)만 쓰면 $n = 4$에서 64개, $n = 5$에서 286개만 정해지므로 이 둘이 실제로 일을 한다. $n = 6$에서는 미지수 3,556개와 방정식 7,989개에서 2,980개가 정해지고 모순이 없다. 576개(156개 군, 위수 2, 4, 8, 16, 전체 NPN 류의 $3.6 \times 10^{-7}$)는 자유도 78이 남는다.

**(C2) 직접 세기.** $L \le B_n$이고 $\varphi \in V(L)$이면, 모든 $g \in L$에서 $f \circ g = f \oplus \varphi(g)$인 함수는 $f(x) = b[\mathrm{orb}(x)] \oplus \mathrm{sgn}(x)$ 꼴이다($b$는 $L$의 꼭짓점 궤도마다 자유로운 비트이고 $\mathrm{sgn}$은 보조정리 3의 증명이 정하는 부호). 이 $2^{o(L)}$개 가운데 안정화군이 정확히 $K = \{(g, \varphi(g)) : g \in L\}$인 것의 수를 $E(L, \varphi)$라 하자. $f$는 $\bar K(f) \supseteq L$을 만족하므로 이 조건은 $\lvert H(f) \rvert + \lvert A(f) \rvert = \lvert L \rvert$과 같다. $K$의 $G_n$ 안 정규화군은 $N_B(L, \varphi) \times \mathbb{Z}_2$($N_B(L, \varphi)$는 $L$을 정규화하고 $\varphi$를 보존하는 $B_n$의 원소들)이므로 $K$와 켤레인 안정화군을 가진 NPN 류는 $E \lvert L \rvert / (2 \lvert N_B(L, \varphi) \rvert)$개이다. $\varphi$를 $N_B(L)$-궤도별로 더하면 $W[j, s] = \dfrac{\lvert L_j \rvert}{2 \lvert N_B(L_j) \rvert} \sum_{\varphi \in V(L_j),\ \mathrm{sig}(\varphi) = s} E(L_j, \varphi)$이다. 서명이 같은 두 $K$는 $\varphi$별로 따로 세어 가른다.

$E$는 $2^{o(L)}$개의 함수를 Gray 부호 순서로 모두 열거해 함수마다 $H$와 $A$를 직접 구해 센다(`scripts/sample_npn_stabilizers.c`의 `enumfix`. 궤도 번호와 부호는 GAP의 `scripts/enum_fix_prep.g`가 만든다). 이 값은 연립방정식이 정한 값과 직접 견줄 수 있다(5절).

$n = 6$에서는 꼭짓점 궤도 수가 24 이하인 군 1,112개(나타나는 1,137개 중)에서 $(L, \varphi)$ 4,003쌍의 함수 618,657,124개를 모두 열거했다(코어 둘로 약 12분). 그 가운데 616,328개는 걸러내기 없이 모든 순열을 시험한 값과 견주어 검산했고 모두 같았다. 열거하지 못한 군은 25개이다(자명군, 위수 2인 군 15개, 위수 4인 군 7개, 위수 6과 8인 군 각 1개. 꼭짓점 궤도 수 26 이상이고 NPN 류 200,253,952,527,184개 가운데 200,253,944,539,926개를 가진다). 이 25개 군의 미지수 37칸 가운데 13칸은 유효한 $\varphi$가 0뿐이라 (D)가 값을 그대로 준다. 나머지 24칸은 $\varphi \ne 0$이 하나 있는 위수 2인 군 12개의 두 칸씩이고, 열거한 3,519칸을 모두 방정식에 넣은 연립방정식이 정한다(방정식 11,508개, 자유도 0, 모순 0). 이 37칸은 열거가 아니라 균일 무작위 표본으로 견주었다(5절).

"$H$로는 나타나지만 $\bar K$로는 안 나타나는" 군 $L$은, $H(f) = L$인 함수가 모두 반대칭을 가진다는 뜻이다(반대칭이 없는 $f$라면 $\bar K(f) = H(f) = L$이 되어 $L$이 $\bar K$로 나타났을 것이다). 가장 작은 예는 $n = 1$의 자명군이다($x$와 $\lnot x$는 입력 반전으로 옮겨진다). $n_g(L) = 0$인 $L$이 $\bar K$로 나타나면 그 류는 모두 반대칭이 없다. $n_g + 1$은 모든 $\bar K$에서 2의 거듭제곱이었고(보조정리 3의 $2^k$와 맞는다), $k = \log_2(n_g + 1)$의 분포는 $n = 6$에서 $k = 0, 1, 2, 3, 4$가 174, 371, 425, 156, 11개이다(`npn_stabilizer_types_summary_output.txt`의 [2]).

### 2.5 대칭이 없는 함수

$\bar K$가 자명한 함수는 $n = 4, 5, 6$에서 18,432개(NPN 류 24개), 3,916,262,400개(509,930개), 18,438,111,408,052,869,120개(200,066,313,021,407개)이다. R9의 $H$가 자명한 함수는 22,656개, 3,926,492,160개, 18,438,115,815,625,098,240개이므로, 차이인 4,224개, 10,229,760개, 4,407,572,229,120개가 "대칭은 없지만 자기보수 대칭이 하나 있는" 함수이다. 이때 $\bar K$의 위수는 2이다. $H$가 자명한 함수 가운데 이런 함수의 비율은 18.64%, 0.2605%, $2.39 \times 10^{-5}\,\%$이다.

## 3. 구조에 대해 알게 된 것

- $K(f) \cong \bar K(f)$이고 $\bar K$는 쌍의 안정화군이므로 NPN 판의 표는 "$B_n$의 부분군 $L$과 $L$의 준동형 $\varphi$"의 자료이다. $\varphi$가 0이 아닐 수 있는 조건은 지수 2인 부분군 $N$이 꼭짓점 궤도를 모두 둘로 가르는 것이다(보조정리 3). 이 조건이 $\bar K$ 단위의 개수를 식으로 준다(1.3절).
- 반대칭이 없는 류의 수 NP $-$ NPN은 OEIS A317794(집합계의 동형류 수)와 같은 값이다. 그 수열의 정의는 이 문제와 무관하고, 같은 값인 것은 OEIS가 A317794 = A000616 $-$ A000370이라고 적기 때문이다. 이 노트의 관계(1.5절)가 이 식과 같은 말이다.
- 고정 꼭짓점이 있는 $H$도 반대칭 원소가 더해지면 $\bar K$는 고정 꼭짓점을 잃는다(2.2절 4행과 8행, 유형 U인데 반대칭 1).
- $K$ 단위의 표는 $B_n$의 표지 표 하나와 두 가지 대칭(꼬인 작용, 패리티 대칭)만으로 거의 정해진다(1.6절). $n = 3, 4, 5$에서는 완전히, $n = 6$에서는 미지수 3,556개 가운데 2,980개가 정해진다. 꼬인 작용은 같은 표지 표에서 $B_n$-궤도 수를 네 가지(곧 $\psi = 0, \psi_1, \psi_2, \psi_3$)로 주고, 패리티 함수 $c$는 $f \mapsto f \oplus c$로 $\varphi$를 $\psi_2$만큼 옮긴다. 이 두 사실이 $B_n \times \mathbb{Z}_2$의 표지 표를 대신한다. 이것이 $n = 7$ 이상에서도 통하는지는 시험하지 않았다.

## 4. 문헌에서의 위치

이 절은 R9 노트 4절의 범위에 11-13에 읽은 것을 더한 것이다. 이 노트와 직접 관련된 것만 적는다.

- NPN 류의 수(A000370)와 NP 류의 수(A000616)는 오래된 값이다(A000370의 참고문헌에 Harrison 1963이 있다). 자기보수 부울 함수의 수(A000610, 이 노트의 반대칭 류 수)는 참고문헌이 Elspas 1960(자기보수 대칭 유형), Toda 1962, Harrison 1963, Palmer–Robinson 1984이다. 이 노트의 "반대칭 류의 총수"는 새로운 값이 아니다.
- Elspas(1960, *IRE Trans. Electronic Computers* EC-9(2), 264–266쪽)는 제목이 자기보수 대칭 유형이라 이 노트의 반대칭과 가장 가깝다. 11-13에 OEIS A000610이 올려 둔 스캔으로 전문을 읽었다. 변수의 순열과 반전으로 옮겨지는 함수를 같은 "대칭 유형"(이 노트의 NP 류)으로 보고, 보수의 유형이 자기 자신과 같은 유형을 "자기보수"라 부른다. Slepian의 합 $N_n = \frac{1}{n!\,2^n} \sum_C n_C 2^{K(C)}$($K(C)$는 연산 류 $C$가 꼭짓점을 나누는 순환의 수)를 순환 가운데 홀수 길이인 것이 있는 류와 없는 류로 갈라 자기보수 유형 수와 아닌 유형 수의 공식을 얻는다(그의 (7), (8)). 개수표가 하나 있다(표 I, $n \le 5$: 자기보수 1, 2, 6, 42, 4,094. 균형 유형 1, 2, 6, 74, 169,112. 전체 3, 6, 22, 402, 1,228,158). 이 수들은 이 노트의 반대칭 류 수(A000610)와 NP 류 수와 같다. 순환 구조를 이동 레지스터와 인버터로 된 회로로 읽는 문단이 있고, 두 종류 유형 수의 점근식을 미해결 문제로 적으며 끝난다. 안정화군의 분류나 군별 함수 수는 없다.
- Harrison(1963, *IEEE Trans. Electronic Computers* EC-12, 559–561쪽의 서신 *The Number of Equivalence Classes of Boolean Functions Under Groups Containing Negation*)과 Toda(1962, *IRE Trans. Electronic Computers* EC-11, 282쪽에서 시작하는 서신 *On the Number of Types of Self-Dual Logical Functions*)는 OEIS A000370, A001531이 올려 둔 스캔으로 일부만 읽었다. Harrison은 앞 두 쪽을 읽었다. 변수 반전군, 변수 순열군, 둘이 만드는 군, 일반 선형군, 아핀군 아래의 동치류 수를 de Bruijn의 정리로 세어 표로 내고(출력의 보수를 같게 보는 경우도 센다), 자기보수 유형 수의 새 유도와 Elspas의 추측을 다룬다고 쓴다(추측의 내용은 읽지 못했다). Toda는 첫머리만 읽었다. 자기쌍대 함수의 수와 그 대칭 유형의 수를 고친 Slepian 방법으로 센다고 한다. 둘 다 개수 세기이고 군별 분해는 보이지 않았다. Harrison은 같은 해 *J. SIAM* 11, 806–828쪽에 *The number of transitivity sets of Boolean functions*도 냈다(서지만 확인했고 읽지 못했다).
- Urquhart(2009, *Bull. Symbolic Logic* 15(3), 273–299쪽)는 Pólya의 해법과 1870년대부터 1970년대까지의 이 문제의 역사를 다룬다. 초록과 Cambridge Core의 참고문헌 55편을 읽었다. 참고문헌에 안정화군을 켤레류별로 센 글은 없고 Golomb, Elspas, McCluskey, Forbes, Lechner도 들어 있지 않다. 전문은 읽지 못했다(Project Euclid는 구독 전용이고, 저자가 확인한 기관 로그인 목록에 인하공업전문대학이 없었다).
- 안정화군을 켤레류별로 세는 일은 R9 노트 4절의 판단과 같다. 입력 반전을 넣은 분류와 군별 함수 수를 읽은 글에서 찾지 못했고, 읽지 못한 글이 남아 있으므로 새롭다고 단정하지 않는다.

- $n = 6$은 전수 점검이 안 된다($2^{64}$개). $\bar K$ 단위의 표(방법 B)는 $B_6$의 표지 표 분해와 합계 검사에 기댄다. $K$ 단위의 표(방법 C)는 그 분해에서 나온 방정식과 군 1,112개의 직접 열거에 기댄다. 두 방법은 $n \le 5$에서 방법 A와 전수 열거로 확인되었으나, 이 확인이 $n = 6$에서도 성립한다는 보장은 아니다. 두 방법이 같은 GAP의 $B_6$ 표지 표를 쓰므로 그 표가 틀리면 같이 틀린다. 표지 표 자체는 합계 검사와 표본 점검이 간접으로 받쳐 줄 뿐이다.
- $n = 6$에서 $B_6 \times \mathbb{Z}_2$(66점 위의 순열군, 위수 92,160)의 표지 표는 구하지 못했다. 방법 A를 $n = 6$에 쓰려면 이 표지 표가 필요하다. GAP의 `TableOfMarks`를 코어 하나, `-o 6g`, 30분 제한으로 돌려 보았으나(`scripts/probe_tom_b6z2.g`) 끝나지 않았다(`notes/probe_tom_b6z2_output.txt`). 그동안 작업 공간 전체의 사용 메모리는 최대 678 MB였고 한도 6 GB에 닿지 않았으므로, 이 30분 동안의 병목은 메모리가 아니라 계산 시간이었다. 더 오래 돌리면 끝나는지, 끝났을 때 메모리가 모자랄지는 모른다. $G_6$의 켤레류 수는 표지 표 없이 Goursat 보조정리로 65,899로 구했다(앞 항에 대한 비는 5.4, 4.9, 7.6, 6.4에 이어 10.3이다).
- $n = 6$ 표에서 직접 센 군은 꼭짓점 궤도 수 24 이하인 1,112개이고, 열거하지 못한 25개 군(NPN 류의 99.99999%, 함수의 99.99999%)의 값은 연립방정식이 정한 것을 균일 표본으로 견주었을 뿐이다(37칸, 칸마다 표본 $5 \times 10^6$개 또는 $3 \times 10^7$개). 통계 점검이라 상대오차 $10^{-4}$ 아래의 어긋남은 알아채지 못한다. 이 군들의 값은 방정식(과 그 밑의 표지 표 분해)이 준다.
- 균일 표본 점검이 시험한 키는 $n = 6$에서 13개뿐이다. 함수의 거의 전부가 이 키들에 든다. 나머지 키(표의 대부분의 행)는 방정식과 열거에 기댄다.
- $n = 6$에서 반대칭 류의 총수가 맞는 것은 독립 점검이 아니다. 연립방정식이 쓰는 정보(NP 류 수와 NPN 류 수)에서 따라 나온다. 서명이 같은 두 $K$가 하나 있어($\bar K$ 류 하나) 그 류는 열거로 가른 값이다.
- 키 단위 비교는 켤레류 하나하나를 구분하지 않는다(R9와 같은 한계). 같은 키를 가진 서로 다른 켤레류의 함수 수가 뒤바뀌어도 이 점검은 알아채지 못한다. 방법 A와 B의 일치와 대표 함수 점검이 이 구멍을 일부 메운다.
- $n \le 5$ 표의 열 21과 $n = 6$ 표의 열 18의 켤레류 번호, 구조 열의 표기는 실행마다 달라질 수 있다. $n \le 5$ 표의 대표 함수는 무작위 탐색의 결과이고, $n = 6$ 표에는 대표 함수가 없다.
- 문헌 검토는 R9 노트 4절의 범위에 11-13에 읽은 Elspas(전문), Harrison 1963과 Toda 1962(일부), Urquhart(초록과 참고문헌)를 더한 것이 전부이다. Golomb 전문, Harrison·Lechner 1971, Forbes 1971은 읽지 못했다.
- 모든 코드와 점검을 같은 계열 AI가 썼다. 저자가 읽거나 돌려 본 것은 아직 없다.

## 6. 다음에 할 수 있는 것

- $n = 6$ 표를 지금보다 강하게 확인하는 일. 열거하지 못한 25개 군의 값(함수의 거의 전부)은 균일 표본 점검뿐이므로, 그 군의 $E(L, \varphi)$를 부분군 격자의 뫼비우스 반전 같은 정확한 방법으로 세거나, 다른 언어와 다른 알고리즘으로 쓴 독립 코드로 열거 가능한 군의 일부를 다시 세어 보는 길이 있다. 어느 쪽도 하지 않았다.
- $n = 7$로 넓히기. 방법 C는 $B_7$(위수 645,120)의 표지 표가 필요한데 $B_6$(위수 46,080)의 표지 표가 7분 걸렸으므로 이 크기의 표지 표는 지금 방식으로는 어려울 것이다. 시험하지 않았다.
- 읽지 못한 글(Golomb 전문, Harrison·Lechner 1971의 4·5장, Forbes 1971. Elspas 1960은 11-13에 읽었고 군별 분해가 없었다)을 구해 군별 분해가 이미 있는지 확인한다. `[저자]`
- 새로움이 확인되면 OEIS에 수열(나타나는 군의 수 등)을 올리거나 수학 질문 사이트에 묻는 글의 초안을 쓴다. 올리는 일은 저자가 정한다.

$n = 6$ 표를 다시 만드는 순서(저장소 맨 위 폴더에서. 시간은 코어 둘인 작업 공간에서 잰 값이다).

1. GAP에서 $B_6$의 표지 표를 만들어 저장한다(7분). `NO_MAIN := true; Read("scripts/npn_pair_resolution.g"); PRE := MakeBn(6); PRE.tom := TableOfMarks(PRE.G); SaveWorkspace("tom6.ws"); QUIT;`를 표준 입력으로 읽힌다. 이어서 `gap -L tom6.ws -A -q 파일.g < /dev/null`로 자료를 내보낸다(5분). 파일에는 `Unbind(NO_MAIN); N_MIN := 6; N_MAX := 6; NA_MAX := 0; OUTDIR := "notes"; Read("scripts/npn_pair_resolution.g");`를 쓴다.
2. `python3 -I scripts/solve_npn_pair_resolution.py notes/npn_pair_data_n6.tsv`로 방정식만 풀어 본다(2초). 정해지지 않은 군의 목록을 얻는다.
3. 열거 작업 파일을 만든다. `gap -L tom6.ws -A -q 파일.g < /dev/null`의 파일에 `JOBS := [군 번호들]; OUTFILE := "작업 파일"; Read("scripts/enum_fix_prep.g");`를 쓴다. 군 번호는 `npn_pair_data_n6.tsv`의 $j$이다. 열거는 `./sampnpn6 enumfix <작업 파일> 1009 > 결과`(1009는 걸러내기 없는 검산 간격)이다. 꼭짓점 궤도 수 24 이하인 1,112개 군 전체를 코어 둘로 약 12분에 센다.
4. `python3 -I scripts/combine_enum_fix.py notes/npn_pair_data_n6.tsv <열거 결과...> --out=notes/npn_pair_fixed_n6.txt`로 고정값을 만들고(`--compare`는 풀이기가 이미 정한 값과 견준다), `python3 -I scripts/make_npn_k_table.py notes/npn_pair_data_n6.tsv 6 notes/npn_stabilizer_types_n6.tsv --fix=notes/npn_pair_fixed_n6.txt --split=<열거 결과...>`로 표를 만든다.
5. 점검. `./sampnpn6 1500000000 <씨앗> > 출력`을 씨앗 둘로 돌리고(각 14분) `python3 -I scripts/compare_npn_sample.py notes/npn_stabilizer_types_n6.tsv 6 <출력들>`으로 견준다. 열거하지 못한 군은 `./sampnpn6 randfix <작업 파일> <표본 수> <씨앗>`으로 표본을 뽑고(두 줄기로 나눠 약 9분) `python3 -I scripts/check_randfix.py notes/npn_pair_data_n6.tsv --fix=notes/npn_pair_fixed_n6.txt <표본 결과>`로 견준다.
