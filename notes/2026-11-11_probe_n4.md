# 탐침 기록: 그림 종류 수와 분해 차트의 다중도 (n = 4)

2026-11-11. 7번 TODO가 9번으로 넘긴 질문("그림 종류 수와 열 다중도 사이에 관계가 있는가")을 4변수 함수 65,536개 전부에서 세어 본 기록이다. 선행 연구 조사는 아직 하지 않았으므로, 아래 관찰이 새로운지는 모른다.

## 무엇을 셌나

- 변수 쌍 분할 세 가지 `AB|CD`, `AC|BD`, `AD|BC` 각각에서 4×4 분해 차트를 만들고, **다중도 쌍** = {서로 다른 행의 수, 서로 다른 열의 수}(순서 없는 쌍)를 구했다.
- $t$ = 그림 종류 수(7번 논문 정리 5; 1, 2, 3). $d$ = 세 분할의 다중도 쌍이 몇 가지인가(1, 2, 3). $s$ = 다중도 2 이하(단순 분해 $f = g(h(X), Y)$가 되는 경우)인 분할의 수.
- 범위는 2변수 | 2변수 분할뿐이다. 1변수 | 3변수 분할과 겹치는(non-disjoint) 분해는 보지 않았다.

## 계산이 맞는지 확인한 것

- $W$-궤도 805개, $B_4$-궤도 402개, $t = 1/2/3$인 함수 3,220 / 36,204 / 26,112개가 7번 논문의 값과 같다.
- $t$를 두 방법(세 배치 그림의 $W$-궤도 비교, 안정화군이 세 분할에 작용하는 궤도 수)으로 계산했고 65,536개 모두에서 같다.
- 스크립트는 7번의 `scripts/`를 보지 않고 정의만으로 새로 짰다. 다만 Claude가 짠 것이고 저자가 아직 검토하지 않았다.

## 읽는 법과 한계

- (나)는 "그림 종류 수가 분해 가능성을 알려 준다"는 방향의 기대에 불리하다. 다중도는 그림보다 훨씬 거친 불변량이다.
- (다)는 반대 방향으로 깔끔하지만 쉽게 설명된다(아래 "(다)의 증명 스케치"). 따름정리 수준의 사실이다.
- 1변수 | 3변수 분할의 분해 차트는 2×8 표여서 4×4 카르노맵의 변수 배치(2|2 분할)와 같은 틀에 놓이지 않는다. 처음에는 이 이유로 보지 않기로 했으나, 저자의 물음을 받고 세어 보았다(아래 "3|1 분할" 절). 결론은 2|2와 같다.

## (다)의 증명 스케치 (2026-11-11 추가, Claude 초안, 저자 검토 전)

**주장.** 4변수 함수 $f$가 어떤 2|2 분할에서 다중도 2 이하이면, 곧 $f = g(h(x_i, x_j), x_k, x_l)$ 꼴이면, 그림 종류 수는 2 이하이다.

- **$h$가 두 변수 모두에 의존할 때.** 그런 2변수 함수 10개는 출력 반전을 무시하면 $(x_i \oplus a)(x_j \oplus b)$ 꼴(AND형 8개)이거나 $x_i \oplus x_j$ 꼴(XOR형 2개)이다. AND형에서는 $(x_i, x_j) \mapsto (x_j \oplus a \oplus b,\ x_i \oplus a \oplus b)$가, XOR형에서는 $x_i \leftrightarrow x_j$가 $h$를 바꾸지 않는다. 어느 쪽이든 $f$의 안정화군에 "변수 순열 부분이 맞바꿈 $(i\ j)$"인 원소가 있다. 이 맞바꿈은 분할 $\{ij \mid kl\}$을 고정하고 나머지 둘을 맞바꾸므로 궤도는 2개 이하이다.
- **$h$가 한 변수 이하에만 의존할 때.** $f$는 $x_i$, $x_j$ 가운데 하나에 의존하지 않으므로 3변수 함수이다. 3변수 함수 256개는 모두 그림 종류 수가 2 이하이다(`picture_type_distribution.g`의 $n=3$ 결과: 52개가 1, 204개가 2). 곧 변수 순열 부분이 자명하지 않은 대칭을 반드시 가진다. 그 순열은 세 변수의 맞바꿈이나 3-순환인데, 둘 다 세 분할에 자명하지 않게 작용한다.

둘째 경우는 $n=3$의 계산에 기대며, 5변수 이상에서는 성립하지 않는다(쓰이지 않는 변수가 있어도 대칭이 없을 수 있다). 첫째 경우는 변수 수와 무관하다: **두 입력이 하나의 2입력 게이트를 거쳐서만 쓰이면 그 두 변수의 맞바꿈이 대칭의 순열 부분에 들어가고, 5·6변수에서 그림 종류 수는 9 이하가 된다.**

$s = 2$인 함수가 없다는 관찰은 증명하지 않았다.

## 3|1 분할 (2026-11-12 추가, Claude 작성, 저자 검토 전)

변수 하나 $x_i$를 따로 두고 나머지 셋을 묶으면 분해 차트는 2행 × 8열이다. 열 다중도 $\mu_i$(서로 다른 열의 수, 1~4)가 2 이하이면 $f = g(h(\text{나머지 셋}), x_i)$ 꼴로 단순 분해된다. 묶음이 변수 하나인 쪽은 다중도가 언제나 2 이하라서 조건이 되지 않는다. $s_3$ = $\mu_i \le 2$인 변수의 수. 스크립트는 `scripts/probe_three_one_partitions.py`, 출력은 `probe_three_one_output.txt`이다.

| | $s_3=0$ | $s_3=1$ | $s_3=2$ | $s_3=3$ | $s_3=4$ |
|:---:|:---:|:---:|:---:|:---:|:---:|
| $t=1$ | 2,112 | 992 | 0 | 0 | 116 |
| $t=2$ | 32,448 | 2,976 | 720 | 0 | 60 |
| $t=3$ | 26,112 | 0 | 0 | 0 | 0 |

- **세 변수를 묶어 단순 분해되는 함수도 그림 종류가 2 이하이다**(예외 0건).
- 2|2든 3|1이든 어느 하나로라도 단순 분해되는 함수는 8,296개이고 모두 $t \le 2$이다. 그림이 세 가지인 26,112개는 어떤 식으로도 단순 분해되지 않는다.
- **까닭.** $h$는 3변수 함수이고, 3변수 함수는 모두 변수 순열 부분이 자명하지 않은 대칭을 가진다($n=3$의 계산). 그 대칭은 $x_i$를 그대로 두고 $f$를 바꾸지 않으며, 순열 부분은 세 변수의 맞바꿈이나 3-순환이므로 세 쌍 분할에 자명하지 않게 작용한다. 2|2의 둘째 경우와 같은 논법이고, 마찬가지로 4변수에서만 통한다.
