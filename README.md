# 9NPNStabilizerTypes — 7번 논문의 후속 연구

[7KarnaughGroupClassification](https://github.com/inha20/7KarnaughGroupClassification)(4변수 카르노맵의 격자 대칭과 그림 종류 수)의 후속 연구를 위한 작업 폴더이다. 학술대회 발표를 목표로 하지 않는 순수 후속 연구이다. 갈래는 둘이다. 그림 종류 수의 일반화(줄기)와 회로 최적화 탐색이다.

**현황, 저자의 결정, 계획은 [`PLAN.md`](PLAN.md)에 있다.** 논문 원고는 없다.

## 실행

- `.py`는 Python 3(표준 라이브러리)만 있으면 된다(`check_general_n_proofs.py`, `check_selfcomplementary_family.py`, `check_npn_bruteforce.py`, `circuit_*.py`는 numpy도 쓴다). 예: `python scripts/check_pictures_by_definition.py notes/class_representatives_n5.txt`
- `.c`는 C 컴파일러가 필요하다. 컴파일과 실행 방법은 파일 머리의 주석에 있다. 5변수 전수 열거는 두 코어에서 5분쯤 걸린다(NPN 판의 `enumerate_npn_stabilizers.c`도 조각 하나가 코어 하나에서 5분쯤). NPN 판 6변수의 `sample_npn_stabilizers.c`(`-DNV=6`)는 균일 표본 $1.5 \times 10^9$개에 코어 하나에서 14분쯤 걸리고, 군별 열거(`enumfix`)는 꼭짓점 궤도 24 이하인 군 1,112개 전체에 코어 둘로 12분쯤 걸린다. `agl52_orbits.c`(AGL(5,2)가, `-DLINEAR_ONLY`를 주면 GL(5,2)가 5변수 함수 $2^{32}$개에 하는 작용의 궤도를 모두 나열)는 코어 하나에서 5분쯤 걸리고 메모리를 2 GB쯤 잡는다.
- `circuit_*.py`는 Yosys가 필요하다(`pip install yowasp-yosys numpy`). `circuit_metrics.py`의 65,536개 전수 측정은 코어 둘에서 40분쯤 걸린다(묶음 16개를 `python scripts/circuit_metrics.py <출력 파일> <묶음 번호>...`로 나눠 돌린다). 정확 합성(`circuit_exact.py`, `circuit_lut_flows.py`, `circuit_multi_output.py`의 일부)은 ABC를 소스에서 빌드해야 한다(<https://github.com/berkeley-abc/abc>, 커밋 `bde1659`, `make ABC_USE_NO_READLINE=1`). 동치류 222개의 AND 수 정확 합성은 두 코어에서 몇 시간이 걸릴 수 있다(어려운 네 동치류는 1,200초 제한으로는 끝나지 않았다). `circuit_exact_vs_krinkin.py`는 Krinkin의 저장소(<https://github.com/krinkin/bounds>, 커밋 `6a82884`)를 따로 내려받아 읽기만 한다(`python3 -I`로 실행한다).
- 회로 실험(C8)의 `circuit_sample_orbits.py`와 `circuit_lut4_exact_n5.py`는 numpy와, 소스에서 빌드한 ABC가 필요하다(`-abc <경로>` 또는 환경 변수 `CIRCUIT_ABC`). 5변수 표본 1,000개(변환 16개씩)는 둘로 나눠 두 코어에서 돌리면 4분쯤 걸렸다. `flows`는 3분 안팎, `relabel`은 변환 수에 따라 1분에서 십여 분이 걸린다(환경 변수는 `circuit_lut4_exact_n5.py` 머리말).
- `.g`는 [GAP](https://www.gap-system.org)이 필요하다. 예: `gap -q scripts/picture_type_distribution.g`. 6변수 계산은 6분쯤 걸린다(NPN 판의 6변수 $\bar K$ 계산은 7분쯤, `-o 6g`. `npn_pair_resolution.g`는 6변수에서 $B_6$의 표지 표 만들기 7분, 자료 내보내기 5분쯤). NPN 판 6변수 $K$ 표를 다시 만드는 순서는 `notes/2026-11-12_npn_stabilizer_types.md` 7절에 있다. 지금까지는 Claude의 작업 공간에서 돌렸다(`PLAN.md` 7절). 안 나타나는 군의 일반 $n$을 점검하는 GAP 스크립트(`agl_burnside_orbits.g`, `gl52_maximal_subgroups.g`, `check_agl_free_witnesses.g`, `check_agl_orbit_stabilizers.g`)는 `gap -A -q -o 3g scripts/<파일> < /dev/null`로 돌리고 각각 1초에서 15초가 걸린다. `check_agl_orbit_stabilizers.g`는 `agl52_orbits.c`의 출력(`notes/agl52_orbits_output.txt`, `notes/gl52_orbits_output.txt`)을 읽는다.
- $B_n$ 부분군 켤레류의 나열과 판정(`np_cegar.py`, `classify_bn_classes.py`, `merge_bn_class_tables.py`, `analyze_bn_absent_classes.py`, `check_bn_absent_certificate.py`, `count_bn_orbits_burnside.py`)은 Python 3에 numpy, scipy, python-sat(pysat)이 필요하다. 전체 흐름은 저장소 맨 위 폴더에서 `GAP=gap bash scripts/run_bn_class_pipeline.sh 작업폴더`이다(코어 둘에 4분쯤. $n = 2, \dots, 6$을 처음부터 나열해 표지 표 방법의 개수와 견주고, $n = 7$은 공개 표를 분석한다). $n = 7$의 나열부터 다시 하는 법과 걸린 시간은 그 스크립트 머리말에 있다. 사용법은 각 파일의 머리말에 있다.
- 안 나타나는 군의 분석(`analyze_unexplained_classes.py`, `export_unexplained_for_gap.py`, `identify_unexplained_overgroups.g`)은 `GAP=gap bash scripts/run_unexplained_analysis.sh 작업폴더 파이프라인작업폴더`로 돈다(코어 하나에 2분쯤, python-sat은 쓰지 않는다). 파이프라인작업폴더는 위 파이프라인에 준 작업 폴더이고, 주지 않으면 $n = 7$만 돈다. `check_n3_minimal_absent_example.py`는 표준 라이브러리만 쓰고 1초 안에 끝난다.
- 안 나타나는 군의 일반 $n$ 점검은 저장소 맨 위 폴더에서 `python3 -I scripts/<파일>`로 돌린다(numpy가 필요하다). `check_dummy_variable_lift.py`, `analyze_absent_reduction.py`, `check_family_in_tables.py`, `check_translation_type_groups.py`, `pure_translation_absent.py`는 위 파이프라인의 작업 폴더(`--pipe`)와 $n = 7$의 공개 표(`--n7`, 마지막 것은 `--annot7`도)를 받는다(인자는 각 파일 머리말). 걸리는 시간은 앞의 셋이 1초 안팎, `pure_translation_absent.py`가 1분 안팎, `check_translation_type_groups.py`가 1분 반쯤이다. `check_pure_translation_n8.py`(10초쯤)와 `check_translation_type_groups.py`의 C 부분은 python-sat이 필요하다. `check_gl_free_functions.py`는 수 초이다. `check_agl_free_witnesses_nauty.py`(2분쯤)와 `check_hamming_transvection_family.py`는 pynauty(`pip install pynauty`)가 필요하다. 저장된 출력은 후자를 `--r 2 3 4 --gap <GAP 실행 파일> --nauty`에 `--family axis`(1분쯤)와 `--family centre`(8~13분)를 각각 주어 만들었다.

## AI 사용 고지

이 폴더의 파일은 저자(최종훈)의 요청으로 Claude(Anthropic)와의 작업 세션에서 만들었다. 저자가 직접 읽거나 실행해 확인한 것은 확인한 날에 이 문서에 적는다. 아직 그런 항목은 없다.
